# Kriptografi

Repository kumpulan slide perkuliahan, materi cipher klasik, latihan soal (ujian/diskusi), serta pengerjaan dan pembahasan tugas Kriptografi.

## Struktur Direktori

- `Kriptoanalisis/`  
  Pengerjaan dan pembahasan tugas kriptoanalisis (termasuk dokumen LaTeX dan PDF).
- `Kriptografi Klasik/`  
  Materi, implementasi, dan catatan algoritma cipher klasik.
- `Lecture Slide/`  
  Slide presentasi materi perkuliahan kriptografi.
- `Past Problems/`  
  Koleksi arsip soal dan pembahasan UTS, UAS, serta diskusi kelompok tahun-tahun sebelumnya.
